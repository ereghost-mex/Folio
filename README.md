# Folio — ebook storefront

A responsive multi-page ebook storefront concept with a minimal editorial style, animated book covers, glassmorphism, and a persistent light/dark theme.

## Pages
- `index.html` — landing page, featured books, newsletter demo
- `shop.html` — searchable and filterable book catalogue
- `about.html` — brand story and values
- `contact.html` — contact form demo

## Run locally
Open `index.html` in a modern browser. No build step is needed. Google Fonts requires an internet connection; fallback fonts are included.

## Demo functionality
- Theme preference and bag count persist in local storage.
- Search and category filters work on the Explore page.
- Add-to-bag buttons update a demo bag counter.
- Newsletter and contact forms show local confirmation only.

## Before accepting real payments
This is a front-end demo, not a production ecommerce backend. Add a secure checkout provider, server-side order handling, protected ebook delivery, real email/form processing, privacy/terms pages, and verified product files. Do not put secret API keys in client-side JavaScript.
